# Experiment results

Full run. Generated by `src/ree/experiments/run_all.py` (`python -m ree.cli experiments`).
Seeds: 10 per scenario (base seed 1000); intervals are 95% t-intervals over seeds. Every number below is computed from the simulated stores of this run.

## Scenarios

- **Balanced assignment** (`balanced`): Random shifts and registers, 12 weeks, veterans only.
- **Biased assignment** (`biased`): Strong cashiers get more peak hours, the card-only lane and smaller baskets; weak cashiers get big baskets and the priority lane.
- **Low data (2 weeks)** (`low_data`): Only two weeks of register data.
- **Heavy interruptions** (`heavy_interruptions`): Customer delays in 15 percent and interruptions in 8 percent of transactions.
- **Newcomers with learning curves** (`newcomers`): A third of the cashiers are hired during the window and speed up with tenure.
- **Shared tills** (`shared_tills`): Cashiers share a drawer on most days they meet at the same register.

## Which method wins where

- **Balanced assignment**: highest mean Spearman is v2 regression (Huber) + pause rule (0.998). Not distinguishable from it over the seeds: v2 regression (OLS) + pause rule. Detectably but trivially lower (under 0.005): v1 bins, no pause rule (-0.002), v1 bins + pause rule (-0.002). Clearly lower: naive items per shift (-0.162), hard 5 s stop (-0.412).
- **Biased assignment**: highest mean Spearman is v1 bins + pause rule (0.988). Not distinguishable from it over the seeds: v1 bins, no pause rule, v2 regression (OLS) + pause rule, v2 regression (Huber) + pause rule. Clearly lower: naive items per shift (-0.936), hard 5 s stop (-0.481).
- **Low data (2 weeks)**: highest mean Spearman is v2 regression (Huber) + pause rule (0.990). Not distinguishable from it over the seeds: v2 regression (OLS) + pause rule. Clearly lower: naive items per shift (-0.469), hard 5 s stop (-0.446), v1 bins, no pause rule (-0.013), v1 bins + pause rule (-0.014).
- **Heavy interruptions**: highest mean Spearman is v2 regression (Huber) + pause rule (0.998). Not distinguishable from it over the seeds: v2 regression (OLS) + pause rule. Detectably but trivially lower (under 0.005): v1 bins, no pause rule (-0.002), v1 bins + pause rule (-0.002). Clearly lower: naive items per shift (-0.173), hard 5 s stop (-0.420).
- **Newcomers with learning curves**: highest mean Spearman is v2 regression (OLS) + pause rule (0.944). Detectably but trivially lower (under 0.005): v2 regression (Huber) + pause rule (-0.002). Clearly lower: naive items per shift (-0.212), hard 5 s stop (-0.619), v1 bins, no pause rule (-0.009), v1 bins + pause rule (-0.010).
- **Shared tills**: highest mean Spearman is v2 regression (Huber) + pause rule (0.998). Not distinguishable from it over the seeds: v2 regression (OLS) + pause rule. Detectably but trivially lower (under 0.005): v1 bins, no pause rule (-0.002), v1 bins + pause rule (-0.002). Clearly lower: naive items per shift (-0.162), hard 5 s stop (-0.412).

**Where the design's own methods (v1 or v2 with the pause rule) lose**

- Low data (2 weeks): v1 bins + pause rule is clearly beaten by v2 regression (Huber) + pause rule (difference 0.014, paired 95% interval 0.007 to 0.021).
- Newcomers with learning curves: v1 bins + pause rule is clearly beaten by v2 regression (OLS) + pause rule (difference 0.010, paired 95% interval 0.003 to 0.017).

Detectable but trivial gaps: Balanced assignment: v1 bins + pause rule trails v2 regression (Huber) + pause rule by 0.002; Heavy interruptions: v1 bins + pause rule trails v2 regression (Huber) + pause rule by 0.002; Newcomers with learning curves: v2 regression (Huber) + pause rule trails v2 regression (OLS) + pause rule by 0.002; Shared tills: v1 bins + pause rule trails v2 regression (Huber) + pause rule by 0.002.

**Where the naive baseline wins or ties**

- Nowhere: it is clearly worse than the best method in every scenario.

Naive items-per-shift baseline, mean Spearman by scenario: balanced 0.84, biased 0.05, low_data 0.52, heavy_interruptions 0.82, newcomers 0.73, shared_tills 0.84.

## Interval calibration

12 replicates of fresh data for the same hidden cashiers (`experiments/calibration.py`). A 90% interval contained the mean score on the other replicates 78.7% of the time over 600 intervals (peak 78.0%, off-peak 79.3%); a perfectly calibrated interval would score about 88.5% at this replicate count.
